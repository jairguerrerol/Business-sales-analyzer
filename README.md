# Business sales analyzer
Proyecto desarrollado en Python para analizar datos de ventas de pequeñas empresas.

Funcionalidades:
Lectura de datos desde Excel
Análisis de ventas
Generación de indicadores
Gráficos automáticos
Reportes para toma de decisiones

Tecnologías:
Python
Pandas
Numpy
Matplotlib
